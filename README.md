# 🔮 Tarot Sanctuary - ไพ่ทาโรต์นำทางชีวิต & ระบบโดเนท PromptPay

เว็บแอปพลิเคชันดูดวงไพ่ทาโรต์แบบ Interactive พร้อมระบบรับโดเนทผ่าน PromptPay QR Code อัตโนมัติ (Zero-Dependency Standalone Web App)

---

## 🌟 ฟีเจอร์หลัก (Key Features)

1. **โหมดการเปิดไพ่หลากหลาย:**
   - 🌟 **ไพ่ประจำวัน:** เปิด 1 ใบ เพื่อรับสารและข้อคิดประจำวัน
   - ❤️ **ความรัก & ความสัมพันธ์:** เปิด 3 ใบ (อดีต - ปัจจุบัน - อนาคต)
   - 💼 **การงาน & การเงิน:** เปิด 3 ใบ (สถานการณ์ - อุปสรรค - ทางออก)
   - 🔮 **ถามคำถามในใจ:** ตั้งจิตอธิษฐานแล้วเปิดไพ่หาคำตอบสำหรับเรื่องที่ค้างคา
   - 🃏 **โหมดไพ่กลับหัว (Reversed):** เปิด/ปิดได้ สลับความหมายไพ่เป็นพลังงานด้านที่ต้องระวัง พร้อมคำทำนายกลับหัวครบทั้ง 22 ใบ
   - 🌙 **ไพ่ประจำวันล็อกวันละครั้ง:** เปิดแล้วจะไม่สุ่มทับจนถึงวันถัดไป (เก็บตามวันที่ในเครื่อง) พร้อมป้าย "ไพ่ประจำวันนี้เปิดแล้ว" และถ้าอยากเปิดใบใหม่ในวันนี้เอง ให้กด "ดูรอบใหม่" แล้วปุ่ม "🔓 ปลดล็อกไพ่ประจำวัน" จะโผล่ขึ้นมาใต้ไพ่ใบนั้น

2. **ประสบการณ์สับไพ่และเปิดไพ่แบบเสมือนจริง (Interactive UX):**
   - สำรับไพ่กรีดโค้ง (Fanned Deck) ให้ผู้ใช้แตะเลือกไพ่ด้วยตัวเอง
   - แอนิเมชันพลิกไพ่ 3D (3D Card Flip) แบบนุ่มนวล
   - ฐานข้อมูลไพ่ทาโรต์ชุดใหญ่ (Major Arcana 22 ใบ) ครบถ้วน คำทำนายละเอียด อบอุ่น และฮีลใจ
   - ⌨️ **ใช้คีย์บอร์ดได้:** Tab เข้ากองไพ่ครั้งเดียว แล้วใช้ลูกศรซ้าย/ขวาเลื่อนดูไพ่ กด Enter หรือ Space เพื่อเลือก พร้อมป้ายบอกสถานะสำหรับโปรแกรมอ่านหน้าจอ

3. **ระบบรับโดเนท TrueMoney Wallet QR:**
   - แสดง QR Code รับเงินผ่าน TrueMoney Wallet รองรับการสแกนผ่านแอป TrueMoney และทุกแอปธนาคาร
   - **📥 บันทึกรูป QR ลงเครื่อง:** สำหรับคนเล่นบนมือถือที่สแกนจอตัวเองไม่ได้ กดครั้งเดียวแล้วเปิดแอปเพื่อสแกนจากรูปได้ทันที
   - ปลอดภัย ไม่เปิดเผยเบอร์โทรศัพท์ส่วนตัวบนหน้าเว็บไซต์

4. **📸 แชร์ผลทำนายเป็นรูปภาพ:**
   - **📸 แชร์ผลไพ่ (1080×1920):** การ์ดแนวยาวเหมาะกับ IG Story / Facebook / LINE — มีรูปไพ่ ชื่อไพ่ ตำแหน่งไพ่ (อดีต/ปัจจุบัน/อนาคต) ความหมายของไพ่ทุกใบ คำแนะนำจากจักรวาล แท็กคีย์เวิร์ดประจำไพ่ สีมงคล และเลขนำโชค
   - **🖼️ โพสต์ฟีด (1080×1080):** การ์ดจัตุรัสสำหรับโพสต์ฟีด Facebook / IG — เนื้อหาย่อให้พอดีพื้นที่ แต่ยังครบทั้งความหมาย คำแนะนำ สีมงคล และเลขนำโชคในบรรทัดเดียว
   - ข้อความไทยตัดบรรทัดด้วย `Intl.Segmenter` ไม่ให้แตกกลางสระ/วรรณยุกต์ และปรับขนาดฟอนต์อัตโนมัติเมื่อเนื้อหายาวเพื่อไม่ให้ล้นขอบหรือทับแถบปิดท้าย
   - หัวข้อชื่อไพ่ทุกใบใช้ขนาดเดียวกัน และย่อพร้อมกันทั้งชุด (ไม่ต่ำกว่า 20px) ถ้าชื่อไพ่ยาว จะได้ไม่มีจุดไข่ปลาและหัวข้อไม่สูงต่ำสลับกัน
   - บนมือถือที่รองรับ Web Share API จะเปิดหน้าต่างแชร์ให้เลือกแอปได้ทันที ถ้าไม่รองรับจะดาวน์โหลดเป็นไฟล์ PNG แทน

5. **🎵 เสียงและสัมผัสเสมือนจริง:**
   - เสียงสับไพ่ เสียงพลิกไพ่พร้อมระฆังแก้ว และเสียงตอบรับเมื่อคัดลอก/บันทึก (สังเคราะห์ด้วย Web Audio API ไม่มีไฟล์เสียงเพิ่ม)
   - ปุ่มเปิด/ปิดเสียง 🔊/🔇 มุมซ้ายบน จำค่าไว้ใน LocalStorage
   - สั่นตอบรับเบาๆ บนมือถือเมื่อแตะเลือกไพ่และตอนเปิดไพ่ (ถ้าเครื่องรองรับ)

6. **ทำงานได้แบบ 100% Standalone:**
   - ไม่ต้องติดตั้ง Node.js หรือรันเซิร์ฟเวอร์ สามารถดับเบิลคลิกเปิดไฟล์ `index.html` บนเบราว์เซอร์ใช้งานได้ทันที (ต้องต่ออินเทอร์เน็ตเพื่อโหลดรูปไพ่จาก Wikimedia)
   - **📲 ติดตั้งเป็นแอป (PWA):** มี `manifest.json` + `sw.js` ให้ "เพิ่มลงหน้าจอโฮม" และเปิดใช้งานออฟไลน์ได้หลังเข้าครั้งแรก — ต้องเปิดผ่าน `http://` หรือ `https://` เท่านั้น (service worker ใช้กับ `file://` ไม่ได้)

---

## 🚀 วิธีเปิดใช้งาน

1. เปิดโฟลเดอร์โปรเจกต์
2. ดับเบิลคลิกเปิดไฟล์ `index.html` ผ่านเบราว์เซอร์ (เช่น Chrome, Edge, Safari)
3. พร้อมใช้งานได้ทันที!

## 🌐 การนำขึ้นออนไลน์ (Deploy to Free Hosting)

คุณสามารถนำโปรเจกต์นี้ขึ้นออนไลน์เพื่อให้คนอื่นเข้ามาเล่นและสแกนโดเนทได้ฟรีๆ ผ่าน:
- **Vercel:** ลากโฟลเดอร์นี้วางเพื่อ Deploy ได้ฟรีใน 1 นาที
- **Netlify:** ลากโฟลเดอร์ไปวางที่ Netlify Drop
- **GitHub Pages:** อัปโหลดขึ้น GitHub Repository แล้วเปิด GitHub Pages

> หลัง deploy แล้ว ควรแก้ `og:image` / `twitter:image` ใน `index.html` ให้เป็น URL เต็ม (เช่น `https://your-domain.com/og-cover.jpg`) เพราะแพลตฟอร์มแชร์ลิงก์ต้องการ URL แบบเต็มจึงจะแสดงภาพพรีวิว
> หากแก้ไฟล์หลัก อย่าลืมเปลี่ยนเลข `?v=` ใน `index.html` และ `CACHE_VERSION` ใน `sw.js` เพื่อให้แคชอัปเดต
