# 🔮 Tarot Sanctuary - ไพ่ทาโรต์นำทางชีวิต & ระบบค่าครูโดเนท PromptPay

เว็บแอปพลิเคชันดูดวงไพ่ทาโรต์แบบ Interactive พร้อมระบบรับค่าครู / โดเนทผ่าน PromptPay QR Code อัตโนมัติ (Zero-Dependency Standalone Web App)

---

## 🌟 ฟีเจอร์หลัก (Key Features)

1. **โหมดการเปิดไพ่หลากหลาย:**
   - 🌟 **ไพ่ประจำวัน:** เปิด 1 ใบ เพื่อรับสารและข้อคิดประจำวัน
   - ❤️ **ความรัก & ความสัมพันธ์:** เปิด 3 ใบ (อดีต - ปัจจุบัน - อนาคต)
   - 💼 **การงาน & การเงิน:** เปิด 3 ใบ (สถานการณ์ - อุปสรรค - ทางออก)
   - 🔮 **ถามคำถามในใจ:** ตั้งจิตอธิษฐานแล้วเปิดไพ่หาคำตอบสำหรับเรื่องที่ค้างคา

2. **ประสบการณ์สับไพ่และเปิดไพ่แบบเสมือนจริง (Interactive UX):**
   - สำรับไพ่กรีดโค้ง (Fanned Deck) ให้ผู้ใช้แตะเลือกไพ่ด้วยตัวเอง
   - แอนิเมชันพลิกไพ่ 3D (3D Card Flip) แบบนุ่มนวล
   - ฐานข้อมูลไพ่ทาโรต์ชุดใหญ่ (Major Arcana 22 ใบ) ครบถ้วน คำทำนายละเอียด อบอุ่น และฮีลใจ

3. **ระบบรับค่าครู / โดเนท PromptPay QR Code (Dynamic QR):**
   - สร้าง QR Code พร้อมเพย์ตามมาตรฐาน EMVCo อัตโนมัติในฝั่งเบราว์เซอร์ (Pure JavaScript)
   - ปุ่มเลือดยอดเงินลัด: **฿19** (ชานม), **฿39** (กาแฟ), **฿99** (ค่าครูมงคล), **฿199** (เปิดดวงใหญ่), หรือยอดตามศรัทธา
   - ปุ่มคัดลอกเบอร์พร้อมเพย์ในคลิกเดียว พร้อมเสียงและข้อความตอบรับ
   - **ระบบตั้งค่าเบอร์พร้อมเพย์ในตัว:** กดไอคอนฟันเฟือง (⚙️) มุมขวาบน เพื่อเปลี่ยนเป็นเบอร์พร้อมเพย์ของคุณเองได้ทันที บันทึกผ่าน LocalStorage ปลอดภัย

4. **ทำงานได้แบบ 100% Standalone:**
   - ไม่ต้องติดตั้ง Node.js หรือรันเซิร์ฟเวอร์ สามารถดับเบิลคลิกเปิดไฟล์ `index.html` บนเบราว์เซอร์ใช้งานได้ทันที

---

## 🚀 วิธีเปิดใช้งาน

1. เปิดโฟลเดอร์ `C:\Projects\tarot-fortune-web`
2. ดับเบิลคลิกเปิดไฟล์ [index.html](file:///C:/Projects/tarot-fortune-web/index.html) ผ่านเบราว์เซอร์ (เช่น Microsoft Edge หรือ Chrome)
3. คลิกที่ไอคอนฟันเฟือง ⚙️ มุมขวาบนเพื่อใส่ **เบอร์พร้อมเพย์ของคุณ** (เช่น `0812345678`) แล้วกดบันทึก
4. พร้อมใช้งานได้ทันที!
